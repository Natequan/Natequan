## Featured engineering work

### Industrial Modbus RTU Integration — Schneider M221 ↔ PowerLogic PM5110
**Industrial Networking · PLC · RS-485 · Modbus RTU · Ladder Logic**

Configured and validated a Schneider industrial serial communication link, including PLC/laptop setup, Modbus parameters, Ladder communication logic, manufacturer register-table lookup, PLC memory mapping and troubleshooting an addressing offset.

### Raspberry Pi Eye-Tracking Writing System
**Python · OpenCV · Raspberry Pi 4B · UDP · Embedded Systems · Computer Vision**

Implemented the Raspberry Pi software for a gaze-controlled writing prototype using pupil detection, image preprocessing, temporal smoothing / Kalman filtering, UDP communication, threading and OLED feedback.

### Low-Cost Automated PCB Prototyping Cell
**Arduino · CNC · Fusion 360 · Proteus · G-code · Digital Manufacturing**

Worked across a hybrid rapid-prototyping workflow combining an Arduino-based CNC plotter, PCB tracing and etching, CAD/CAM, PETG 3D printing, laser fabrication and ShopBot machining.

### IoT Irrigation & AC Pump Control
**Embedded Control · IoT · Sensors · Power Electronics · ESP32-class Systems**

Developed a cyber-physical irrigation prototype using capacitive soil-moisture sensing, embedded control, live IoT variables and an optoisolated TRIAC-based AC pump stage.
